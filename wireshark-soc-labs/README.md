# Wireshark SOC Labs

A growing collection of hands-on Wireshark labs for SOC analysts. Each lab covers one protocol: a capture, the normal baseline, the attacks that abuse it, the filters to find them, and detection ideas mapped to MITRE ATT&CK.

> **Note:** the captures in this repository are **synthetic**. They are generated by scripts included in each lab, not recorded on real networks. All addresses are private (RFC 1918) or documentation ranges (RFC 5737), so nothing points at real systems.

## Labs

|---|---|---|---|

The planned labs are ideas and may change.

## How each lab is structured

Every lab follows the same layout, so you always know where to look:

```
labs/NN-protocol/
  README.md              overview, results table and embedded evidence
  FINDINGS.md            analyst write-up: evidence, verdict, ATT&CK, action
  SCREENSHOT_GUIDE.md    the filters and screenshots for every scenario
  pcap/                  the capture
  scripts/               generator for the capture
  screenshots/           Wireshark evidence
```

A blank starting point for new labs is in [labs/_template](labs/_template).

## What you'll practise

- Telling normal protocol behaviour from malicious behaviour
- Building and tuning Wireshark display filters
- Using Statistics views (Conversations, Endpoints, I/O Graphs, Expert Information)
- Writing evidence-based findings and mapping them to MITRE ATT&CK
- Proposing detections and mitigations

## Tools

Wireshark and Python 3 (standard library only).

## Limitations

The captures are synthetic and cleaner than production traffic, which has far more noise. Verdicts are based on the packets in each capture and can't prove intent or impact on their own.
