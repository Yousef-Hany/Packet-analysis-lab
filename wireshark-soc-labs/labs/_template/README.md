## Checklist for a new lab (delete this section when done)

1. Copy this folder to `labs/NN-protocol/` and rename it.
2. Write `scripts/generate_pcap.py`, generate the capture, and check the packet counts and checksums.
3. Analyse it in Wireshark and take screenshots with the filter bar visible. Number the files in order.
4. Fill in `FINDINGS.md`: evidence, verdict, ATT&CK mapping and recommended action for each finding.
5. Write `SCREENSHOT_GUIDE.md` with the filter for each scenario.
6. Add the lab to the table in the top-level README.
